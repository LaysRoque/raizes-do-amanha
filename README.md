# raizes-do-amanha
Projeto front-end desenvolvido para uma ONG fictícia, conectando pessoas, projetos e oportunidades para transformar comunidades.
## Acessibilidade

O projeto foi desenvolvido considerando boas práticas de acessibilidade, incluindo:

- Uso do atributo `lang="pt-BR"` no HTML;
- Estrutura semântica com elementos como `header`, `main`, `section` e `footer`;
- Botão de menu com `aria-label`;
- Navegação organizada por links e títulos;
- Layout responsivo para diferentes tamanhos de tela.
